# Data policy

This package includes only dataset metadata manifests and the tiny query
manifest. NY, FLA, CAL, and controlled exact road-network/temporal files are
excluded because redistribution rights and/or size are unresolved. The
manifest fields retain input checksums and portable `EXCLUDED_EXTERNAL_INPUT`
markers; they do not point to a personal filesystem.

Obtain authorized inputs separately, verify the manifest checksums, and record
the download/provenance details before running Level 2/3 experiments.
